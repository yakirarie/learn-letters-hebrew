# לומדים עברית - Learn Hebrew Letters and Numbers

An interactive educational web app for children to learn Hebrew letters, numbers, and basic math in a fun and engaging way.

## Features

### 📚 Letters Learning
- Learn all 22 Hebrew letters with their pronunciation
- Each letter is associated with example words and pictures
- Click on the letter to hear its sound
- Browse through letters with navigation buttons

### 🔢 Numbers Learning
- Learn numbers 1-30 with proper Hebrew pronunciation
- Numbers are displayed with visual object representations
- Proper Hebrew grammar for counting objects:
  - Number 1: Object comes first (e.g., "תַּפּוּחַ אֶחָd" - one apple)
  - Number 2: Uses "שְׁנֵי" form (e.g., "שְׁנֵי כַּdּוּrִים" - two balls)
  - Numbers 3-10: Standard form (e.g., "שְׁלוֹשָׁה פְּrָחִים" - three flowers)
  - Numbers 11-19: Masculine forms (e.g., "אַחַד עָשָׂr" - eleven)

### ➕➖ Math Practice
- Simple addition and subtraction exercises
- Visual representation with emojis for better understanding
- Subtraction shows remaining items (normal) and subtracted items (faded)

### 🎮 Games
- **Quiz**: Mixed questions about letters, numbers, and math
- **Tracing**: Practice writing letters and numbers on a canvas
- **Memory**: Match letters with their corresponding pictures

## Technical Features

- **PWA Support**: Installable as a Progressive Web App
- **Responsive Design**: Works on phones, tablets, and desktops
- **Offline Support**: Works offline after initial load
- **Text-to-Speech**: Hebrew pronunciation using Web Speech API
- **Touch Friendly**: Optimized for touch interactions

## Usage

Simply open `index.html` in a web browser. No installation required.

For best experience:
- Use a modern browser (Chrome, Edge, Safari, Firefox)
- Enable sound to hear pronunciations
- Use in portrait mode on mobile devices

## Technologies Used

- HTML5, CSS3, JavaScript (Vanilla)
- Web Speech API for text-to-speech
- Service Worker for offline support
- CSS Grid and Flexbox for responsive layout
